## 2. Default Seed Wallets

The seed fixtures utilize two well-known public test addresses:
- **Account 1**: `0x0FcD93659FA339bB05A2A12Ed7000dFD714E0998`
- **Account 2**: `0x3f073b4f50D2B2486B632DFB4c7005FC449cED14`

> [!WARNING]
> Because `createShipment()` enforces `receiver != msg.sender`, do not attempt to ship directly between organizations assigned to the same wallet (e.g. Manufacturer → Retailer or Distributor → Warehouse). Use alternating legs:
> **Manufacturer (Account 1) → Distributor (Account 2) → Retailer (Account 1)**.

## 3. Re-Seeding the Database

To reset and apply seed fixtures on host development:
```powershell
pnpm db:seed
```
To force-recreate all seed records, set `FORCE_SEED=true`:
```powershell
$env:FORCE_SEED="true"; pnpm db:seed
```
